ASSETS
======

Drop images here, e.g. `photo.jpg`.

To use a real photo in the scratch card:
1. Copy your photo into this folder as `photo.jpg`.
2. Open `js/main.js` and set the PHOTO_URL value:
       const PHOTO_URL = "assets/photo.jpg";
3. Reload the page — the scratch card will reveal your photo instead of the placeholder.
